¿Qué hace esta página?

Este es el proyecto base de la Actividad 06. Sirve como evidencia de un flujo de trabajo automatizado (CI/CD) que va desde una rama de trabajo (feature branch) hasta la publicación final en producción, pasando por una revisión de código y un entorno de prueba (Preview Deployment).

Flujo implementado

  1. Se crea una rama feature/* con un cambio.
  2. El push dispara el workflow de integración continua (lint/validación).
  3. Se abre un Pull Request hacia main.
  4. El workflow despliega automáticamente un Preview del cambio.
  5. Se revisa el Preview y el código (Code Review) antes de aprobar.
  6. Al hacer merge a main, se despliega la versión final en producción.

Versión desplegada automáticamente vía GitHub Actions.
